# Checkout Store

Single-product store with a mobile-first card checkout (React + Redux) backed by a NestJS API on AWS Lambda + DynamoDB, integrated with a payment provider sandbox.

> Work in progress — built with Spec-Driven Development ([spec-kit](https://github.com/github/spec-kit)) and TDD. Specs live under `specs/`, project principles in [`.specify/memory/constitution.md`](.specify/memory/constitution.md).
